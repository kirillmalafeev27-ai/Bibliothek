# Слепой библиотекарь · Der blinde Bibliothekar

Тихая игра про немецкий язык — пятая в серии после «Сокровищницы», «Шахты», «Льдин»
и «Костров до рассвета». Ночью в старой библиотеке хозяйничает слепой библиотекарь:
он ничего не видит, зато слышит всё. Искатель сокровищ пробирается между стеллажами
за тремя листами старинной карты. Каждый верный ответ — тихий шаг или бросок словаря.
Ошибка — с полки с грохотом падает книга, и если библиотекарь рядом, он идёт на звук.

Выглядит игра как средневековая рукопись: пергамент, железо-галловые чернила, темпера
и сусальное золото. Весь арт и весь звук создаются процедурно при запуске — ни одной
картинки и ни одного аудиофайла.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

```bash
npm test           # правила, генератор на 1000 сидов, банк вопросов, темп
npm run build      # проверка типов и сборка в dist/
npm run e2e        # Playwright: скриншоты, тест читаемости слуха, «пройти раунд»
npm run sim -- --level 4 --runs 2000     # симуляция ботами
npm run sim -- --all --runs 1000         # все уровни и сверка с целями раздела 14
```

Параметры адреса в dev-сборке: `?level=N` — сразу в игру, `?art=gray` — серый прототип,
`?scene=hearing` — сцена теста читаемости слуха, `?scene=sprites` и `?scene=kit` —
листы текстур и рукописного кита, `?q=edge` — вопросы с длинными словами.
Клавиша `` ` `` открывает отладочную панель.

## Управление

| Действие | Касание или мышь | Клавиатура |
|---|---|---|
| Ответить | табличка варианта | 1–4 |
| Идти | тап по клетке | стрелки |
| Бросить словарь | «Бросить», затем тап по клетке в круге | T, стрелки — прицел, Enter — бросить, Esc — отмена |
| Стоять | тап по герою или «Стоять» | Пробел |
| Пауза | кнопка паузы | P или Esc |

## Встраивание

```ts
import { mountLibrary } from './src/embed';

const game = mountLibrary(container, {
  questions,            // QuestionProvider: next(): Promise<Question>, report(r)
  storage,              // по умолчанию localStorage с префиксом library:
  level: 1,
  onFinish: (r) => console.log(r.won, r.stars),
});
game.destroy();
```

## Устройство

- `src/core` — чистая логика без Phaser: редуктор `reduce(state, action)`, слух
  `hears()`, библиотекарь, герой, генератор уровней. Детерминирована сидом.
- `src/config` — все числа баланса, уровни и палитра.
- `src/shared` — общие модули серии: панель вопроса, темп игрока, раскладка с темами,
  переключатель качества, звуковой микшер, рукописный кит `manuscriptKit.ts`.
- `src/art` — манифест текстур, фабрика и рецепты рукописного арта.
- `src/render`, `src/scenes` — отрисовка на Phaser 4; сцены только читают состояние.
- `src/app` — приложение: раунд, экраны, обучение, сохранение.
- `tools/sim.ts` — симуляция четырьмя ботами на настоящем движке правил.

Отступления от плана и их причины — в [DECISIONS.md](DECISIONS.md).
