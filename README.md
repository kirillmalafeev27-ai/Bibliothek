# Слепой библиотекарь · Der blinde Bibliothekar

Тихая игра про немецкий язык — пятая в серии после «Сокровищницы», «Шахты», «Льдин»
и «Костров до рассвета». Ночью в старой библиотеке хозяйничает слепой библиотекарь:
он ничего не видит, зато слышит всё. Искатель сокровищ пробирается между стеллажами
за тремя листами старинной карты. Каждый верный ответ — тихий шаг или бросок словаря.
Ошибка — с полки с грохотом падает книга, и если библиотекарь рядом, он идёт на звук.

Выглядит игра как средневековая рукопись: пергамент, железо-галловые чернила, темпера
и сусальное золото. Весь арт и весь звук создаются процедурно при запуске — ни одной
картинки и ни одного аудиофайла.

Вопросы сочиняет ИИ — движок вопросов Morskoy, перенесённый из «Костров до рассвета»:
игрок выбирает уровень A1–C1, лексическую тему (44 темы, среди них «Bibliothek und Bücher»,
«Märchen und Sagen», «Mittelalter und Burgen») и до пяти тем грамматики, а сервер игры
присылает задания в девяти форматах — инструкция по-русски, немецкий материал и четыре
варианта, часто целыми предложениями. Пока генерации нет, вопросы — из встроенного банка.
Как это устроено и какие инструкции получает модель — в [docs/GENERATION.md](docs/GENERATION.md).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 — игра и API вопросов
```

Генерации нужен ключ AI Tunnel (или другого OpenAI-совместимого API) в окружении или в
`.env.local` — он не коммитится; без ключа игра работает на встроенном банке, а свои наборы
слов — и без него. Озвучка аудирования — ключ ElevenLabs, без него читает голос браузера.

```bash
AITUNNEL_API_KEY=… npm run dev
```

```bash
npm test           # правила, генератор уровней, банк вопросов, темп, движок генерации, API
npm run build      # проверка типов, сборка игры в dist/ и сервера в dist-server/
npm start          # боевой сервер: игра и API на http://localhost:3000
npm run e2e        # Playwright: скриншоты, тест читаемости слуха, «пройти раунд», квиз
npm run test:quiz  # только квиз: выбор тем, ожидание, аудирование, раскладка 9 форматов
npm run sim -- --level 4 --runs 2000     # симуляция ботами
npm run sim -- --all --runs 1000         # все уровни и сверка с целями раздела 14
npm run sim -- --compare-gen             # банк против заданий генератора
```

Деплой (Northflank, Docker, переменные окружения) — в [DEPLOY.md](DEPLOY.md).

Параметры адреса: `?q=bank` — только встроенный банк, без выбора тем; `?level=N` — сразу
в игру. В dev-сборке ещё `?art=gray` — серый прототип, `?scene=hearing` — сцена теста
читаемости слуха, `?scene=sprites` и `?scene=kit` — листы текстур и рукописного кита,
`?q=edge` — вопросы с длинными словами. Клавиша `` ` `` открывает отладочную панель.

## Управление

| Действие | Касание или мышь | Клавиатура |
|---|---|---|
| Ответить | табличка варианта | 1–4 |
| Идти | тап по клетке | стрелки |
| Бросить словарь | «Бросить», затем тап по клетке в круге | T, стрелки — прицел, Enter — бросить, Esc — отмена |
| Стоять | тап по герою или «Стоять» | Пробел |
| Пауза | кнопка паузы | P или Esc |
| Повторить фразу (аудирование) | «Слушать» | — |

## Встраивание

```ts
import { mountLibrary } from './src/embed';

const game = mountLibrary(container, {
  questions,            // QuestionProvider: next(): Promise<Question>, report(r)
  storage,              // по умолчанию localStorage с префиксом library:
  level: 1,
  onFinish: (r) => console.log(r.won, r.stars),
});
game.destroy();
```

Источник с выбором тем — `AiQuestionProvider` (`src/shared/questions/AiQuestionProvider.ts`)
с встроенным банком в запасе: тогда в меню появляется кнопка «Вопросы». Любой другой
`QuestionProvider` работает как раньше.

## Устройство

- `src/core` — чистая логика без Phaser: редуктор `reduce(state, action)`, слух
  `hears()`, библиотекарь, герой, генератор уровней. Детерминирована сидом.
- `src/config` — все числа баланса, уровни и палитра.
- `src/shared` — общие модули серии: панель вопроса (с форматом заданий генератора), темп
  игрока, раскладка с темами, переключатель качества, звуковой микшер, рукописный кит
  `manuscriptKit.ts`; `src/shared/questions` — встроенный банк, ИИ-источник с очередями по
  темам, темы и озвучка аудирования.
- `server` — сервер игры: инструкции для ИИ и проверка заданий (`server/generation`), свои
  наборы слов (`server/vocab`), API вопросов и озвучки; без Express.
- `src/art` — манифест текстур, фабрика и рецепты рукописного арта.
- `src/render`, `src/scenes` — отрисовка на Phaser 4; сцены только читают состояние.
- `src/app` — приложение: раунд, экраны, обучение, сохранение, темп по видам вопросов.
- `tools/sim.ts` — симуляция четырьмя ботами на настоящем движке правил.

Отступления от плана и их причины — в [DECISIONS.md](DECISIONS.md).
